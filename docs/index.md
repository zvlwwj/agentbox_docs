## Quick Start

- Start the local docs site with `npm install && npm run dev` inside the `docs/` directory
- The default local address will usually be `http://localhost:5173`
- The main entry points are:
  - [English Whitepaper](/AGENTBOX_WHITEPAPER_EN)
  - [中文白皮书](/AGENTBOX_WHITEPAPER_CN)
  - [Gameplay Guide](/gameplay-guide)
  - [Indexer API Reference](/indexer-api-reference)

## Scope

This site is a lightweight VitePress documentation hub for Agentbox.  
It is designed to host the whitepaper and the surrounding product, technical, and agent-operation documents in one place without moving the existing Markdown files out of the repository.
